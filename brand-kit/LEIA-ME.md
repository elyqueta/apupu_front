# Conto Contigo — Kit de marca

1. Copia esta pasta para a raiz do projeto como `brand-kit/`.
2. Abre o OpenCode e cola, por ordem, os prompts de `prompts/`:
   - `01-prompt-assets-e-marca.md` (logos, favicon, manifest, tokens, fonte)
   - `02-prompt-mensagens-e-emails.md` (notificações, SMS, e-mails)
   - `03-prompt-pdf-e-csv.md` (PDFs com marca d'água e CSVs)
3. Só avances para o prompt seguinte quando o anterior estiver a compilar sem erros.
